World Builder

Read-only tileset inspector + map previewer. Reads live from src/core/textures.ts and src/data — nothing here is duplicated by hand, so it can't drift from what the game actually renders. Run npm run dev and open /tools/world-builder/.

Map preview

Click a tile in the tileset panel to select a brush, then click or drag on the map to paint. Picking a tile not yet in this map's legend adds it automatically.

Drag a rectangle on the tileset panel to select the stamp's source art, then click the map to place it. Drag an existing stamp on the map to move it; delete it from the Stamps table below.

source: none selected

Click the map to place an NPC, pick its sprite from the bank, then Add. Drag an existing NPC to move it.

sprite none selected

Click the map to place a door, choose its target, then Add. Drag an existing door to move it.

Click the map to place/move a spawn point (an existing key is overwritten).
